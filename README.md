# 📊 Sentiment Analysis Web Application

A lightweight, user-friendly Natural Language Processing (NLP) web application designed to analyze text and predict its underlying emotional tone (Positive, Negative, or Neutral) in real-time.


Live Project Link = https://sentiment-analysis-project-kfqp.onrender.com/
---

## 🚀 Features

- **Real-Time Sentiment Prediction:** Instantly analyze customer reviews, social media comments, feedback, or custom text.
- **Clean & Intuitive UI:** Minimalist interface focused on fast predictions and clear results.
- **RESTful API / Backend Integration:** Powered by a robust backend script capable of processing text inputs efficiently.
- **Cloud Hosted:** Deployed and accessible globally via Render.
